### Task 3: `ImageData` validation and messages

**Interfaces (exact text):**
- **Format error:** `` `Invalid format: must be ${formatNames}; got ${shown}.` `` plus a hint. `shown` is the value through the existing `describe` helper if `index.js` or `shared.js` has one, else `JSON.stringify` for strings and `typeof` otherwise. Hints:
  - for a known name in another case: `` ` Format names are lower case: '${lower}'.` ``
  - for `'argb'`/`'xrgb'`: `" Cairo and node-canvas ARGB32 is BGRA in memory on little-endian machines, and premultiplied: convert it to straight alpha and pass 'bgra' (see Input in the API docs)."`
  - for `'bgr'`: `" 24-bit BGR isn't supported: widen each pixel to 4 bytes and pass 'bgrx'."`
- **`ImageData` with `colorType` other than `'rgba'`:** `` `Invalid image: this ImageData holds '${colorType}' pixels, and an ImageData is read as 8-bit RGBA.${suggest}` `` where `suggest` is `` ` Pass { data: imageData.data, format: '${f}', width, height } instead.` `` for `'bgra'` (f `'bgra'`) and `'rgb888x'` (f `'rgbx'`), and `" Ask for colorType 'rgba'."` otherwise.
- **`ImageData` length:** `` `Invalid image: this ImageData's data has ${n} bytes, but ${width} x ${height} RGBA pixels need ${width * height * 4}.` ``
- **VideoFrame hint**, for objects with `copyTo` and `codedWidth`, checked before the `close` check: `" Got a VideoFrame: copy its pixels with frame.copyTo(buffer, { format: 'BGRA' }) and pass { data: buffer, format: 'bgra', width: frame.displayWidth, height: frame.displayHeight } (or 'BGRX' and 'bgrx' for frames without alpha)."`
- **Missing-format hint:** `` ` It has \`data\` but no \`format\`: add one of ${formatNames} to use it as a RawImage.` ``
- **`tooLarge`:** "about 480 megapixels of RGBA" becomes "about 480 megapixels at 4 bytes per pixel".
- **Detached buffers:** the worker entry uses the main entry's wording for a detached `data`.
